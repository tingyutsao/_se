rust-curl
輕量、模組化的 curl 風格 HTTP 客戶端

以 Rust 與 reqwest 實作，保留 curl 最常用的指令介面， 同時帶來彩色輸出、下載進度條與清楚的模組分工。

安裝 快速開始 所有選項

功能

CLI flags 與 curl 慣例一致，migration 成本低。

HTTP/2 + rustls

預設啟用 HTTP/2，TLS 走 rustls 與 webpki-roots，不需要系統 OpenSSL。

串流與進度條

以 chunk 串流下載並顯示即時進度；輸出非 TTY 時自動隱藏。

Proxy & SOCKS

-x 支援 [PROTOCOL://]HOST:PORT，含 socks5。

壓縮與編碼

gzip 自動解壓，charset 協助判斷文字編碼，binary 內容原樣輸出。

Multipart 表單

-F key=value 與 -F key=@file 皆可，建立標準 multipart body。

計時與指標

內建 elapsed 計時，可用 -w 輸出狀態碼、速度、耗時等變數。

安裝

需要 Rust 1.74 以上。

# 從 crates.io 安裝
cargo install rust-curl

# 或直接從原始碼建置
git clone <this-repo> && cd rust-curl
cargo build --release
./target/release/rust-curl --help
# 檢查版本
rust-curl --version

用法

網址若省略 scheme，會自動補上 http://。

# 基本 GET
rust-curl https://example.com

# 顯示回應標頭
rust-curl -i https://example.com
# POST 表單資料
rust-curl -X POST -d "name=alice&age=30" https://api.example.com/users

# 自訂標頭 + Basic Auth
rust-curl -H "Accept: application/json" -u user:pass https://api.example.com/me
# 上傳 multipart 表單檔案
rust-curl -F "title=report" -F "file=@./data.csv" https://api.example.com/upload

# 下載檔案（以遠端檔名）＋ 跟隨轉向
rust-curl -L -O https://example.com/archive.zip

# 輸出到指定檔案，並印出統計
rust-curl -s -o out.json -w "%{http_code} %{size_download}B %{time_total}s\n" https://example.com/api
# 走 proxy、限時、詳細模式
rust-curl -v -x socks5://127.0.0.1:1080 -m 10 --connect-timeout 3 https://example.com

所有選項

由 clap 4 定義，rust-curl --help 可取得同樣內容。

短長說明
<URL> — 要抓取的網址（必填）
-X--requestHTTP 方法：GET / POST / PUT / DELETE / HEAD / OPTIONS / PATCH，預設 GET
-H--header自訂標頭，格式 Name: Value，可重複
-d--data請求主體（自動補 Content-Type）
--data-binary @FILE從檔案讀取請求主體
-i--include在輸出中包含協定回應標頭
-o--output FILE輸出寫到檔案而非 stdout
-O--remote-name以遠端檔名寫入目前目錄
-L--location跟隨 HTTP 轉向
--max-redirs NUM最多跟隨的轉向次數，預設 10
-m--max-time SECONDS整體傳輸時間上限
--connect-timeout SECONDS連線時間上限
-u--user USER:PASSBasic Auth 認證
-x--proxy [PROTOCOL://]HOST:PORT使用代理
-s--silent靜默模式，不顯示進度與額外資訊
-v--verbose詳細模式，印出請求與回應標頭
-w--write-out FORMAT傳輸後輸出格式化統計
-F--form KEY=VALUE\|@FILEmultipart 表單欄位，可重複

Write-out 變數

用於 -w；\n、\r、\t 會被展開成對應控制字元。

變數單位說明
%{http_code}
%{response_code}		—HTTP 回應狀態碼（兩者等價）
%{size_download}bytes下載的內容大小
%{speed_download}bytes/s平均下載速度
%{time_total}秒整體傳輸耗時
%{url_effective}—實際請求的最終網址
%{time_namelookup}
%{time_connect}
%{time_appconnect}
%{time_pretransfer}
%{time_redirect}
%{time_starttransfer}		秒各階段耗時指標（保留欄位，目前固定為 0）
