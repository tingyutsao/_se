系統架構

        瀏覽器 (你)
            │  http://localhost:8080
            ▼
   ┌──────────────────────────────────────────┐
   │  nginx  ── 反向代理 + 靜態網站            │
   │  /            → 本頁面（靜態檔案）        │
   │  /api/node/   → node-api:3000            │
   │  /api/python/ → python-api:8000          │
   │  /api/rust/   → rust-api:8080            │
   └───────┬──────────────┬──────────┬────────┘
           │ webnet       │          │
           ▼              ▼          ▼
     node-api:3000   python-api:8000  rust-api:8080
           │ datanet (唯一可連資料庫)
           ▼
     PostgreSQL:5432  ← 具名 volume 保存資料

規則：只有 nginx 對外開放埠號；三個 API 只在 Docker 內部網路上互相可見。
