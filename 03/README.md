# CampusPulse 輕量校園匿名交流與二手揪團社群

> 零依賴、免建置、雙擊即開的校園 CMS 展示專案：匿名牆 + 二手市集 + 揪團看板。
> 純原生 HTML5 + CSS3 + JavaScript（ES6），資料存於瀏覽器 `localStorage`。

## 1. 為什麼有價值

- **解決真實痛點**：跨系選課評價、二手器材交易、運動揪團在大群組易被洗版，本專案以「分區看板 + 標籤 + 搜尋/排序」提高資訊密度。
- **低門檻高隱私**：一鍵匿名切換，滿足心聲、課業提問、意見回饋的真實表達需求。
- **面試作品集亮點**：涵蓋 CMS 內容管理、樹狀留言關聯、狀態管理、模糊比對、本地持久化。
- **商業延伸**：頂部贊助橫幅、二手板「付費置頂 24hr」徽章機制已預留展示位。

## 2. 功能一覽

| 需求 | 實作位置 | 說明 |
|---|---|---|
| 分區看板 | `index.html` 側欄 + `app.js: BOARDS` | 全部 / 閒聊匿名牆 / 二手市集 / 運動揪團，附即時篇數 |
| 貼文身分 | 發文 Modal（`#postModal`） | 自訂暱稱或完全匿名（隨機如「匿名小鹿」） |
| 分類標籤 | `app.js: TAGS` | 看板連動選單，如 `#請益 #出售 #揪團`；支援標籤 chips 過濾 + 熱門標籤雲 |
| 推/噓 | `vote()` | 每篇本機限投一次，重複點擊取消，數值同步儲存層 |
| 留言串 | 詳情 Modal（`#detailModal`） | 點擊貼文展開，支援 `@回覆` 巢狀顯示 |
| 排序 | 頂部 `最新/熱門` | 最新 = timestamp 降冪；熱門 = 讚數降冪；置頂文永遠在前 |
| 模糊搜尋 | 頂部搜尋框 | 標題 + 內文 + 標籤 + 作者即時比對（大小寫不敏感） |
| 持久化 + 重置 | `app.js: Storage` | `localStorage` 讀寫防呆，壞檔自動回退種子資料；一鍵重置展示 |

## 3. 快速開始

1. 用檔案總管進入本目錄（`03/`）。
2. 雙擊 `index.html`，用瀏覽器開啟即可（Chrome / Edge 皆可）。
3. 無需 `npm install`、無需伺服器、無需資料庫。

```text
03/
├── index.html   # 主頁版面（頂欄 / 側欄 / Feed / 發文+詳情 Modal）
├── styles.css   # 雙欄 Feed 樣式、卡片、Modal、RWD
├── app.js       # Storage / CRUD / 投票 / 搜尋排序 / 留言（ES6 module）
└── README.md    # 本文件
```

## 4. 操作指南（課堂展示建議 3 分鐘）

1. **首屏**：已內建 9 篇種子資料，展示置頂揪團文 + 贊助文徽章。
2. **搜尋排序**：輸入「羽球」即時過濾 → 切「🔥熱門」看讚數排序。
3. **投票防呆**：對同一貼文按兩次「▲推」，第二次會取消並 Toast 提示。
4. **留言回覆**：點卡片進詳情 → 留一則留言 → 對他人留言按「↩回覆」。
5. **發文**：按「＋我要發文」→ 關匿名不填暱稱會被擋（表單驗證展示）→ 成功後 Toast + 置頂於全部看板。
6. **重置**：按右上「↺重置展示」還原種子資料。

## 5. 資料模型（JSON Schema）

```json
{
  "id": "post_1001",
  "board": "market",
  "tag": "出售",
  "author": "羽球愛好者",
  "isAnonymous": false,
  "pinned": false,
  "sponsored": false,
  "title": "出清九成新 Yonex 拍與重訓手套",
  "content": "換新裝備故售出…",
  "likes": 12,
  "timestamp": "2026-10-04 10:15",
  "comments": [
    {
      "commentId": "c_01",
      "author": "匿名小鹿",
      "content": "請問球拍型號與握把規格？",
      "timestamp": "2026-10-04 10:20",
      "replyTo": "羽球愛好者"
    }
  ]
}
```

- `localStorage` 鍵：`campuspulse_posts_v1`（貼文陣列）、`campuspulse_votes_v1`（`{ postId: 1 | -1 }`）。
- 匿名代號：`ANON_PRE × ANON_ADJ` 隨機組合。
- 時間：`YYYY-MM-DD HH:mm` 字串，排序時以 `Date.parse` 轉換。

## 6. 技術選型

| 元件 | 採用技術 | 原因 |
|---|---|---|
| 介面 | 原生 HTML5 + CSS3（Flexbox/Grid） | 零打包、文字編輯器即可開發 |
| 邏輯 | 原生 JavaScript（ES6 modules） | 免 Node 模組，記憶體佔用極低 |
| 儲存 | `localStorage` API | 零伺服器、離線可用 |
| 圖標 | Unicode / 內嵌 Emoji | 免外部字體庫，載入零延遲 |

## 7. 已知限制與後續延伸

- 單機儲存：換瀏覽器/清快取資料即消失；要多裝置同步需接後端（如 Firebase / REST API）。
- 單層留言：目前以 `replyTo` 模擬巢狀，未做無限層縮排。
- 可延伸：圖片上傳、檢舉機制、虛擬點數置頂金流、深色模式、PWA 離線安裝。
