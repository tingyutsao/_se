# 💳 SubKeeper 訂閱管家

一個**純前端、零相依、離線可用**的訂閱支出管理網頁。記錄你所有的訂閱服務（Netflix、Spotify、ChatGPT、雲端空間……），自動算出每月與每年總支出，在扣款前提醒，並協助你找出可以取消的項目。

> 🔒 資料只存在你的瀏覽器（localStorage），不需要註冊、不上傳任何伺服器。

## 為什麼要做這個？

- **自己就是使用者**：訂閱單筆金額小，但加總後每月常達數千元，多數人說不出自己到底訂了什麼、一年花多少錢，也常忘記取消試用或年繳方案。
- **高頻且真實的痛點**：只要有訂閱習慣的人都適用。
- **隱私友善**：打開即用，資料不出裝置。

商業價值（延伸方向）：免費增值模式（免費版限制筆數，付費版提供雲端同步與推播提醒），或客製給小型團隊盤點 SaaS 支出。本專案僅實作基本功能，不涉及商業化。

## 快速開始

不需安裝任何東西，直接用瀏覽器打開 `index.html` 即可。

```powershell
# 或在本地起個靜態伺服器（擇一即可）
npx serve .
python -m http.server 8080
```

建議第一次使用時先按「📋 載入範例資料」看看整體效果。

## 功能

| 功能 | 說明 |
|---|---|
| 新增／刪除訂閱 | 名稱、金額、幣別（TWD／USD／JPY／EUR）、週期（月／季／年）、下次扣款日、分類 |
| 支出統計 | 自動換算每月與每年總支出（以 TWD 顯示） |
| 扣款時間表 | 依下次扣款日排序，顯示「N 天後扣款」，**7 天內**整列以警示色標示 |
| 考慮取消標記 | 一鍵標記，即時算出「取消後每年可省金額」 |
| 過期自動順延 | 過去的扣款日會自動依週期順延到第一個不早於今天的日期 |
| 分類占比 | 各分類的每月支出、百分比與橫條圖 |
| 本機儲存 | 重新整理後資料仍在；清除瀏覽器資料後回到空狀態（不會報錯） |
| 範例資料／清空 | 一鍵載入 8 筆範例；清空前有確認對話框 |
| 深色模式＋RWD | 跟隨系統 `prefers-color-scheme`；手機上自動改為卡片式版面 |

## 技術設計

- 純 HTML / CSS / JavaScript，**無建置工具、無外部套件**，離線可開。
- 資料存於 localStorage，key 為 `subkeeper-v1`；讀寫皆包 `try/catch`。
- 所有使用者輸入以 `textContent` 渲染（不用 `innerHTML`），輸入 `<script>` 也只會以純文字顯示，**不會被執行**。

### 資料模型

```js
{ id, name, amount, cur: 'TWD'|'USD'|'JPY'|'EUR',
  cycle: 'month'|'quarter'|'year', next: 'YYYY-MM-DD',
  cat, flag: boolean }
```

### 核心計算

- **匯率常數**（對 TWD，固定估計值，介面已標示僅供參考）：TWD 1、USD 32、JPY 0.21、EUR 35。
- **每月成本** = 金額 × 匯率 ÷（月 1、季 3、年 12）。
- **過期順延**：扣款日早於今天時，依週期往後推到第一個不早於今天的日期；月末溢位會夾到該月最後一天（例如 1/31 → 2/28，之後維持每月 28 日，符合多數訂閱服務的實際行為）。
- **可省金額** = 所有被標記「考慮取消」的訂閱，每月成本加總 × 12。

## 驗收測試

核心計算已以 Node 腳本驗證（11/11 通過，見下方摘要）：

| 案例 | 預期 | 結果 |
|---|---|---|
| Netflix 390 TWD 每月 | 每月 390、每年 4,680 | ✅ |
| ChatGPT 20 USD 每月 | 每月 640 TWD | ✅ |
| 年繳扣款日 2024/1/2（今天 2026/10/30） | 順延為 2027/1/2 | ✅ |
| 今天／未來的扣款日 | 不變動 | ✅ |
| 月末 1/31 順延 | 2/28，之後維持 28 日 | ✅ |
| 標記 448 月繳＋1,188 季繳取消 | 每年可省 10,128 元 | ✅ |
| 名稱輸入 `<script>` | 以純文字顯示，不執行 | ✅ |

其他手動驗收：重新整理資料仍在；清除 localStorage 後顯示空狀態且不報錯；手機寬度版面正常。
