# Agent 學習筆記（Week 12）

## 三個核心元件

1. **LLM**：負責「決定下一步」，不負責真正執行程式。
2. **Tools**：由你的程式提供，真正執行計算、讀檔、查資料。
3. **Loop**：把工具結果放回 messages，再問模型一次，直到模型不再要求工具。

## 一句話定義

> Agent = LLM + Tools + Loop + State

## 常見誤解

- 模型沒有記憶：每次都要把 history 送進去。
- 模型不能真的執行工具：它只回傳 `tool_calls`，執行的是你的程式。
- 工具結果要當成「不可信資料」，不要讓它覆蓋 system prompt。

## 安全的工具設計

- 只給完成任務「最小必要」的權限。
- 檔案工具只能讀 sandbox，並阻擋 `../` 與 symlink 逃逸。
- 寫入、付款、刪除等動作，應該加上人工確認。
- 為 Agent 設定 maxSteps，避免無限迴圈。
