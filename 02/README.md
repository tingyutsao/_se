# 金門大學校務系統（模擬示範版）

以金門大學學生校務系統為雛型所製作的**純前端模擬程式**，重現登入、選課、課表、成績、請假與個人資料等主要流程。

> **本系統為教學模擬用途，所有學生、教師、課程、成績與公告資料均為虛構，不具任何效力，亦請勿輸入真實個資。**

---

## 執行方式

不需要安裝任何套件、編譯器或啟動伺服器。

```powershell
start index.html
```

或直接於檔案總管中雙擊 `index.html`，以瀏覽器開啟即可。建議使用 Chrome、Edge 或 Firefox。

| 項目 | 說明 |
|------|------|
| 執行環境 | 支援 ES6（`const`／`let`）與 `Element.closest` 的現代瀏覽器，例如 Chrome、Edge、Firefox 近三年版本 |
| 外部相依 | 無（不需 npm、Node.js、Python 或任何 CDN／網路連線） |
| 檔案數量 | 1 個（`index.html`，HTML + CSS + JS 全含） |
| 檔案大小 | 約 80 KB |
| 系統需求 | 記憶體占用極低，可在低階筆電順暢執行 |

## 功能模組

### 1. 登入與首頁儀表板
- 學號／密碼驗證，錯誤訊息分為「學號不存在」與「密碼錯誤」
- 登入狀態存於 `sessionStorage`，重新整理頁面不會被登出
- 學期統計卡：本學期已選學分、修課門數、上學期加權平均、待審核假單
- **待修課表提醒**：列出尚未修畢的系上必修課，並標註「名額已滿」或「本學期未選」
- 加選／退選截止倒數
- 校園公告（置頂排序）

### 2. 選課系統
- 31 門課程（含資工、企管、數學、觀光、英文、護理與通識課程）
- 五重篩選：關鍵字（名稱／代號／教師）、類別、開課系所、白天／夜間、選課狀態
- **衝堂偵測**：自動標示與已選課程重疊的科目，並於選課前確認時列出衝突明細
- **名額管理**：名額進度條，滿員自動禁止選課
- **學分上限**：每學期上限 20 學分，超過即拒絕
- **超學分機制**：達 18 學分須填寫「超學分理由」並留存
- **重修擋截**：已修及格科目不得重複選修
- 已修課清單與退課作業，退必修課時額外警告

### 3. 課表查詢
- 週一至週五 × 第 1～8 節的彩色課表，滑鼠停留可查看教師與教室
- 夜間課程獨立列表
- 修課明細總表（學分、教師、教室、時段、類別）

### 4. 成績查詢
- 5 個學期分頁（115-1 進行中，標示「尚未輸入成績」）
- 學期加權平均，等第換算 A～F
- 0 學分科目顯示「通過」，不列入加權平均
- 不及格科目以紅字標示
- 歷年修業進度：累計學分、累計平均、累計不及格
- **列印成績單**：輸出正式版面（學籍資料 + 明細表 + 平均），並附列印版面最佳化

### 5. 請假作業
- 假別、起訖日期、事由表單，天數自動計算並含首日
- **自動判讀審核結果**：
  - 病假 1 日內、公假 3 日內、喪假 7 日內 → 系統自動核准
  - 病假 2～5 日、事假 3 日內 → 送系上輔導教師審核
  - 超出上述天數 → 加送導師／系主任審核
- 送出前顯示所需繳交證明
- 待審核假單可撤回，單號自動編號，記錄審核者與送件時間

### 6. 個人資料
- 學籍資料（學號、姓名、系所、班級、學年、狀態）唯讀
- 聯絡方式維護：手機、信箱、地址、緊急聯絡人（附格式驗證）
- 修改密碼：驗證原密碼、8 字元且含英文與數字、變更後自動登出
- 學籍摘要與「重設所有資料」

## 檔案結構

全部程式碼集中於單一檔案 `index.html`，共 1545 行。以註解分區如下：

| 行數 | 區段 | 內容 |
|------|------|------|
| 7–187 | CSS | 登入畫面、系統框架、元件、課表格線、Modal／Toast、列印版面、RWD |
| 189–238 | HTML | 登入畫面、系統框架、Modal、Toast 容器 |
| 240–412 | 資料 | 學期、時段、科系、**課程資料**、**學生資料**、**歷年成績**、公告、**業務規則** |
| 413–718 | CORE | 可容忍的儲存層、資料庫讀寫、時段解析、色彩配置、工具函式、Modal、分頁路由（TABS / VIEWS / BIND 三段式） |
| 719–907 | 頁面 | 首頁儀表板、課表查詢 |
| 908–1290 | 頁面 | 選課系統、成績查詢 |
| 1291–1539 | 頁面 | 請假作業、個人資料 |
| 1540–1542 | 啟動 | `init()` |

### 頁面擴充方式
每個頁面由三個部分組成，新增頁面只需照此模式擴充：

```js
VIEWS.xxx = function () { return '...HTML...'; };   // 產生頁面內容
BIND.xxx  = function () { /* 綁定事件 */ };        // 渲染後執行
```
再於 `TABS` 陣列加入 `{ id: 'xxx', name: '顯示名稱' }` 即完成。

## 模擬規則

所有業務邏輯集中於資料區的 `RULES`（第 391 行），可一處修改、全系統生效。

| 規則 | 設定值 |
|------|--------|
| 每學期修課上限 | 20 學分 |
| 超學分門檻 | 18 學分（須填理由） |
| 加選／退選截止 | 2026-10-16 17:00 |
| 假別 | 病假、事假、公假、喪假 |
| 自動核准 | 病假 ≤1 日、公假 ≤3 日、喪假 ≤7 日 |
| 單次請假上限 | 30 日 |
| 等第換算 | A 90、A- 85、B+ 80、B 75、C+ 70、C 65、D 60、E 50、F <50 |
| 加權平均 | Σ(成績×學分) ÷ Σ(學分)，0 學分不計 |

課程資料採壓縮陣列格式撰寫，於載入時展開為物件並建立時段索引：

```js
['CS301', '作業系統', 3, '黃信誠', '資訊大樓503', '2:1-2 4:1-2', 40, 31, '必修', '41']
//  代號      名稱    學分  教師      教室           上課時間      名額 已選 類別  系所
// 時段「2:1-2」= 週二第 1～2 節；夜間寫成「N1:1-2」
```

## 技術說明

- **無框架**：原生 HTML／CSS／JavaScript，未使用 React、Vue 或 jQuery
- **無建置步驟**：不需 bundler、npm 或編譯，原始碼即執行碼
- **無後端**：純前端模擬，資料寫入 `localStorage`（鍵名 `kmun.sss.v1`）
- **穩健的儲存層**：`localStorage` 讀寫以 `try/catch` 包覆，若瀏覽器限制 `file://` 儲存（部分環境會），自動降級為記憶體模式並於頁面註明，功能仍可完整操作
- **防呆處理**：所有使用者輸入於寫入 DOM 前經 `esc()` 轉義
- **資料與邏輯分離**：課程、學生、規則等資料集中於檔首，畫面僅讀取變數，新增科目不需更動邏輯
- **響應式**：窄螢幕下自動調整選單與內距
- **離線可用**：不載入任何外部字型、CDN 或網路資源，斷網亦可執行
- **列印最佳化**：`@media print` 隱藏導覽列，僅輸出成績單

## 已知限制

本專案為單一檔案模擬程式，以下為刻意簡化的部分：

1. 無伺服器驗證，帳密比對於前端完成，僅供教學演示
2. 名額數字為靜態模擬值，各帳號之間不會實際互相影響
3. 審核流程為規則自動判讀，未實作教師／系主任的審核操作介面
4. 僅提供學生檢視，未實作教師、教務處等後台角色
5. 選課紀錄僅存於當前學期，未實作歷年選課歷程查詢
6. 課程資料於載入時展開為物件，需重新整理頁面才會套用資料層的變更
7. 未處理瀏覽器間 `localStorage` 容量差異（容量約 5 MB，本程式資料量極小）
